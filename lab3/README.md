# Метод обертань Якобі (C++)

## Про проект

Цей код є реалізацією **методу обертань Якобі** на C++ для знаходження власних значень та власних векторів симетричної матриці.

Програма написана як єдиний файл `jacobi_lab_3.cpp` і не потребує зовнішніх бібліотек, окрім стандартних (`<iostream>`, `<vector>`, `<cmath>`, `<iomanip>`).

## Як запустити

1.  **Налаштування матриці**:
    Відкрийте файл `jacobi_lab_3.cpp` і змініть матрицю `A` всередині функції `main()`:
    ```cpp
    int main() {
        // Вхідна матриця (повинна бути симетричною)
        Matrix A = {
            {2.3, 3.5, 1.4},
            {3.5, 0.4, 0.6},
            {1.4, 0.6, 1.3}
        };
        // ...
    }
    ```

2.  **Компіляція**:
    Використовуйте C++ компілятор, наприклад `g++`:
    ```bash
    g++ -o jacobi jacobi_lab_3.cpp -std=c++11
    ```

3.  **Запуск**:
    Виконайте скомпільований файл:
    ```bash
    ./jacobi
    ```

## Вивід програми

Програма детально виводить весь процес розв'язання:

* **Ітерація 0**: Початковий стан матриць `A` та `V`.
* **Ітерація N**: Стан матриць `A` та `V` після кожного обертання.
* **Кінцевий результат**:
    * Діагональна матриця `A` (власні значення на діагоналі).
    * Список власних значень ($\lambda$).
    * Матриця `V` (власні вектори у стовпцях).
