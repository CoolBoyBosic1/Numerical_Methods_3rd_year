# Пошук кореня нелінійного рівняння методами інтерполяції

Програма на C++ для розв'язання задачі з чисельних методів.

## 1. Умова задачі

Знайти **найбільший від'ємний корінь** нелінійного рівняння:
`f(x) = x³ - 4x² - 4x + 13 - sin(x) = 0`

Для пошуку використати два методи:
1.  **Пряма інтерполяція** (метод хорд).
2.  **Обернена інтерполяція** (з використанням інтерполяційного полінома Лагранжа).

Обидва методи мають бути реалізовані з використанням **10 вузлів**, які є нулями полінома Чебишова.

## 2. Етапи реалізації

### Крок 1: Локалізація кореня

Перш ніж будувати вузли, корінь потрібно локалізувати (знайти інтервал `[a, b]`, де функція змінює знак).

* `f(0) = 13` (додатне)
* `f(-1) = -1 - 4 + 4 + 13 - sin(-1) ≈ 12 + 0.84 = 12.84` (додатне)
* `f(-2) = -8 - 16 + 8 + 13 - sin(-2) ≈ -3 + 0.91 = -2.09` (від'ємне)

Отже, найбільший від'ємний корінь знаходиться на інтервалі **`[a, b] = [-2, -1]`**.

### Крок 2: Побудова вузлів Чебишова

Для `n = 10` вузлів, спочатку знаходимо нулі полінома Чебишова $T_{10}(t)$ на відрізку `[-1, 1]`:
$$t_k = \cos\left(\frac{(2k + 1)\pi}{2n}\right), \quad k = 0, \dots, n-1$$

Потім перетворюємо ці вузли `t_k` на наш робочий інтервал `[a, b] = [-2, -1]`:
$$x_k = \frac{b - a}{2} t_k + \frac{a + b}{2} = 0.5 \cdot t_k - 1.5$$

Програма обчислює ці 10 вузлів `x_k` та відповідні їм значення `y_k = f(x_k)`.

### Крок 3: Метод 1 (Пряма інтерполяція)

Цей метод реалізовано як **метод хорд** на основі вузлів Чебишова.
1.  Програма шукає два сусідні вузли `(x_i, y_i)` та `(x_{i+1}, y_{i+1})`, між якими функція змінює знак (`y_i * y_{i+1} < 0`).
2.  До цих двох точок застосовується формула лінійної інтерполяції (формула хорди) для знаходження наближення кореня:
    $$x^* \approx x_i - y_i \frac{x_{i+1} - x_i}{y_{i+1} - y_i}$$

### Крок 4: Метод 2 (Обернена інтерполяція)

Цей метод використовує **всі 10 вузлів** `(x_k, y_k)`.
1.  Будується обернений поліном Лагранжа `G(y)`, який проходить через точки `(y_k, x_k)`.
2.  Корінь рівняння `f(x) = 0` відповідає значенню `y = 0`.
3.  Тому наближення кореня знаходиться як `x* ≈ G(0)`.
4.  Формула в коді реалізує обчислення `G(0)`:
    $$x^* \approx G(0) = \sum_{k=0}^{n-1} \left( x_k \cdot \prod_{j=0, j \neq k}^{n-1} \frac{y_j}{y_j - y_k} \right)$$
